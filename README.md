# 📚 Book Review System

A desktop-based **Book Review System** developed using **Python**, **Streamlit**, and **MySQL** that enables users to manage books, submit reviews, rate books, and store review data efficiently through an interactive graphical user interface.

---

## 🚀 Features

- 📖 Add new books to the collection
- ⭐ Rate books
- ✍️ Write and save book reviews
- 🔍 Search books
- 📂 Store data using MySQL database
- 🖥️ User-friendly graphical interface
- 💾 Persistent data storage

---

## 🛠️ Technologies Used

- Python 3.x
- Streamlit(GUI)
- MySQL

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Saubhagya-M/Book-review-system.git
```

### Navigate to the Project Folder

```bash
cd Book-review-system
```

### Install Required Libraries

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python Book-Review-System.py
```

---

## 💻 Application Workflow

1. Launch the application.
2. Browse or search for books.
3. Select a book.
4. Add your review and rating.
5. Save the review to the SQLite database.
6. View and manage stored reviews.
